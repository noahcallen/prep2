# React Email Lookup Challenge

This is a React-based coding challenge designed to evaluate your ability to work with conditional rendering, data handling, and UI behavior in a small React application.

---

## 📦 Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/email-lookup-challenge.git
   cd email-lookup-challenge

npm install
npm start

💼 Candidate Instructions
This React application allows users to enter an email address and search for a matching user in a local dataset.

🛠 What You Need to Do
1. Apply Conditional Styling
Update the UI so that users with a "Premium" account type are visually styled differently from others.

2. Handle Missing Data
One of the users in the data has a missing email field. Ensure that this does not break the UI and is handled appropriately.

3. Fix the Default Message Behavior
A default welcome message appears before the first search. It should not appear after a search has been performed, regardless of the result.

4. Ensure Reliable Matching
One of the email addresses in the data contains surrounding whitespace. Make sure email lookup works reliably in all cases.
